# Skyline Global Industries

React/Vite implementation of the Skyline Global Industries B2B manufacturer/exporter website.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (normally http://localhost:5173).

## Build

```bash
npm run build
```

The visual system follows DESIGN.md and the page/routing architecture follows ARCHITECTURE.md. Product imagery is intentionally abstract in this first implementation while catalogue collage images are prepared for the next asset pass.
